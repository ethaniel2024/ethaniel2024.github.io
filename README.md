# Ethan Nelson Notes

A GitHub Pages-ready static site for the IS 201 web-development final project. It contains professional writing/resume pages, a from-scratch efficiency lab, a linked single-page interactive app, an image, nested lists, an embedded YouTube video, and a live Tableau embed.

## Publish to GitHub Pages

1. Create or open the target repository on GitHub.
2. Upload these files at the repository root (including `assets/`, `styles/`, and `articles/`).
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/(root)`.
4. After GitHub finishes deployment, use the generated URL. The landing page is `index.html`; the from-scratch page is `scratch.html`.

## Tableau workbook

The from-scratch page embeds Ethan’s published live Tableau Public view, **NBA Shot Efficiency: The Court Has Changed**. The local `.twbx` workbook contains the source dashboards.
